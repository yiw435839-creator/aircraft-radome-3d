## 📖 项目简介
本项目针对航空工程领域机载天线罩设计效率低、重复劳动多、规范查阅繁琐的痛点，开发了一套基于大模型RAG（检索增强生成）的智能设计系统。用户只需用自然语言描述设计需求，系统即可自动检索航空设计规范知识库，生成可直接运行的FreeCAD参数化建模代码，并输出STEP通用工业数模，大幅提升天线罩初步设计效率。

项目面向民用飞机机载天线罩设计场景，覆盖外形设计、结构设计、材料选型、工程计算等全流程，符合民用航空设计基本规范。

---
## ✨ 核心功能
- 🤖 **AI智能生成**：自然语言输入设计需求，自动生成FreeCAD参数化建模代码
- 📚 **专业知识库**：内置6大类航空设计规范，覆盖设计、材料、适航、气动等专业内容
- 📐 **参数化建模**：全参数化设计，尺寸可灵活调整，支持快速迭代
- ⚖️ **工程计算**：自动计算体积、重量、表面积等工程参数
- 📦 **标准输出**：导出STEP通用格式，可直接导入CATIA、UG、SolidWorks等工业软件
- 🎯 **航空特色**：针对机载天线罩优化，符合民用航空设计基本规范

## 🚀 快速开始
### 1. 环境要求
- Windows 10/11
- Python 3.10+
- FreeCAD 1.1.3
- DeepSeek API密钥

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

### 3. 配置密钥
复制 `env.example` 并重命名为 `.env`，填入你的DeepSeek API密钥：
```env
DEEPSEEK_API_KEY=你的DeepSeek API密钥
```

### 4. 运行演示
```bash
python rag_demo.py
```
按照提示输入天线罩设计需求，系统将自动检索知识库并生成FreeCAD建模代码。

### 5. 生成三维模型
将生成的代码复制到FreeCAD Python控制台运行，即可自动生成三维模型并导出STEP文件。

## 📚 知识库内容
系统内置专业航空天线罩设计知识库，涵盖：
1. **设计基础规范**：外形设计、壁厚设计、法兰设计标准
2. **常用材料参数**：玻璃钢、聚四氟乙烯、石英纤维复合材料等性能参数
3. **建模规范**：FreeCAD参数化建模标准、单位规范、命名规范
4. **适航基础要求**：结构强度、环境适应性、维护要求、重量控制
5. **气动设计要点**：外形原则、安装位置、表面质量、阻力影响
6. **类型选型指南**：椭球形、锥形、平板形、流线型天线罩适用场景

## 📝 示例：DA42飞机GPS天线罩
### 设计参数
| 参数 | 值 |
|------|----|
| 外形尺寸 | 300×200×90 mm |
| 壁厚 | 2 mm |
| 材质 | 玻璃钢 |
| 法兰尺寸 | 250×200×10 mm |
| 安装孔 | 6×M6，沿φ180mm圆周分布 |

### 生成效果
- 椭球形流线外形，符合航空气动要求

- 底部方形安装法兰，便于机身安装
- 6个均布安装孔，符合标准螺栓规格
- 自动输出STEP通用数模
